# QuickSave

우클릭 한 번으로 할 일과 링크를 즉시 저장하는 크롬 익스텐션

**개발 기간:** 2026년 5월 18일 ~ 5월 21일

---

## 주요 기능

### 저장
- **우클릭 저장** — 어느 페이지에서든 우클릭 → "할 일로 저장" / "LATER로 저장"
- **드래그 선택 → 메모 자동입력** — 텍스트를 선택한 채로 저장하면 선택 텍스트가 메모에 자동 채워짐
- **빠른 할 일 추가** — 팝업 상단 입력창에서 URL 없이 텍스트만으로 즉시 추가

### 관리
- **TODO / LATER 탭 분리** — 할 일과 나중에 읽을 링크를 탭으로 구분
- **완료 체크** — TODO·LATER 모두 체크박스 제공, 완료 시 취소선 표시
- **항목 고정(Pin)** — 핀 버튼으로 상단 고정, 보라 왼쪽 테두리로 시각적 구분
- **드래그 정렬** — 드래그&드롭으로 우선순위 직접 조정 (고정 항목은 고정 영역 내에서만 이동)
- **메모 / 태그 / 알림 편집** — 편집 버튼으로 언제든 수정 가능

### 검색 & 필터
- **전체 검색** — 제목·메모·태그를 TODO/LATER 통합 검색
- **태그 필터** — 태그 버튼 클릭으로 해당 태그 항목만 표시

### 알림
- **Windows 알림** — 편집 모달에서 날짜·시각을 직접 지정하면 해당 시각에 Windows 시스템 알림 발생
- **미완료 뱃지** — 아이콘에 미완료 TODO 개수를 보라색 뱃지로 표시

### 설정 & 데이터
- **단축키** — 기본 `Alt+Shift+Q`, 팝업에서 ON/OFF 및 키 조합 변경 가능
- **내보내기 / 가져오기** — JSON 파일로 전체 데이터 백업·복원 (중복 항목 자동 스킵)
- **주간 통계** — 이번 주 TODO 저장 수·완료 수·완료율 확인

---

## 설치 방법

1. 이 저장소를 다운로드 또는 클론
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** 활성화
4. **압축해제된 확장 프로그램을 로드합니다** 클릭
5. 다운로드한 폴더 선택

---

## 사용 방법

| 작업               | 방법                                         |
| ------------------ | -------------------------------------------- |
| 페이지 저장        | 페이지에서 우클릭 → 메뉴 선택                |
| 팝업 열기          | 아이콘 클릭 또는 `Alt+Shift+Q`               |
| 할 일 빠른 추가    | 팝업 상단 입력창에 입력 후 Enter             |
| 메모/태그/알림 편집 | 항목의 ✏ 버튼 클릭                          |
| 항목 고정          | 항목의 📌 버튼 클릭                          |
| 순서 변경          | 항목을 드래그해서 원하는 위치에 놓기         |
| 데이터 백업        | 설정(≡) → 내보내기                           |

---

## 기술 스택

- **Manifest V3** Chrome Extension
- HTML / CSS / Vanilla JavaScript
- `chrome.storage.local` — 데이터 영구 저장
- `chrome.alarms` + `chrome.notifications` — Windows 알림
- `chrome.contextMenus` — 우클릭 메뉴
- `chrome.scripting` — 토스트 알림 삽입
- Google Favicons API — 사이트 파비콘
